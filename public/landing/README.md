# Afbeeldingen voorpagina

Zet hier de foto's uit het Pansa-ontwerp. Ontbreekt een bestand, dan toont de pagina een
donkergroene gradient op die plek — er verschijnt nooit een kapot plaatje. Aanbevolen: JPG,
≤ 300 KB, 1600 px breed voor de hero, 600×500 px voor de kaarten.

| Bestand | Waar |
|---|---|
| `logo.svg` of `logo.png` | Logo in de topbar en als watermerk (vierkant, transparante achtergrond) |
| `hero.jpg` | Achtergrond van de hero (industrieel terrein, zonsondergang) |
| `vacatures.jpg`, `sollicitatie.jpg`, `profiel.jpg`, `trainingen.jpg`, `nieuws.jpg`, `bedrijven.jpg` | Kaarten 01–06 in de modus **Werkzoeken** |
| `vacature-plaatsen.jpg`, `kandidaten.jpg`, `beheer.jpg`, `onboarding.jpg`, `rapportages.jpg`, `contract.jpg` | Kaarten 01–06 in de modus **Voor bedrijven** |
